# История изменений

## 1.3.6 — 2026-10-10

### Fixed
- Запись на странице школы, если ролик вставлен плеером Kinescope (`kinescope.io/embed/...`), больше не отвечает «такой сайт не поддерживается». Так устроены и лендинги вебинаров, и часть уроков GetCourse.

## 1.3.5 — 2026-10-09

### Fixed
- Страница вебинара Pruffme (адрес вида pruffme.com/landing/...) больше не отвечает «такой сайт не поддерживается»: Качалка берёт файл записи.

## 1.3.4 — 2026-10-07

### Added
- Вход из браузера запоминается. Первый раз браузер нужно закрыть полностью, вместе со значком в трее. Дальше закрытый ролик скачивается с сохранённым входом, даже если браузер открыт. Чтобы обновить вход, закрой браузер ещё один раз.
- Так для каждого браузера, который отдаёт cookies: Яндекс.Браузер, Firefox, Opera, Brave и Chromium. Chrome и Edge по-прежнему не отдают cookies другим программам. Файл `cookies.txt` по-прежнему важнее сохранённого входа.

## 1.3.3 — 2026-10-07

### Added
- Поле «Имя файла»: до скачивания видно, как ролик называется, и имя можно поправить. У Facebook из начала убираются просмотры и реакции. Окончание .mp4 или .mp3 добавляется само.

## 1.3.2 — 2026-10-06

### Fixed
- В списке cookies для закрытых роликов ВК есть Яндекс.Браузер. Перед скачиванием его нужно закрыть полностью, вместе со значком в трее.
- Chrome и Edge больше не просят закрыть браузер из-за ошибки Windows DPAPI: эти браузеры не отдают cookies другим программам.

## 1.3.1 — 2026-10-04

### Fixed
- Страница школы на своём домене со встроенным плеером GetCourse больше не отвечает «такой сайт не поддерживается»: Качалка берёт ролик из плеера.
- Значок расширения узнаёт ролик по адресу открытой вкладки (YouTube, ВК, Rutube и другие). В первой выкладке список на странице ролика часто был пустым.

## 1.3.0 — 2026-10-01

### Added
- Расширение для Chrome и Яндекс.Браузера: значок на открытой странице показывает ролики. Если их несколько, каждый отмечается галочкой, и Качалка скачивает выбранные по очереди.
- После установки программы папка расширения лежит в `%LocalAppData%\Kachalka\extension`.

## 1.2.1 — 2026-10-01

### Fixed
- «Обзор» открывает одно окно выбора папки текущей Windows. Раньше сначала появлялось старое окно, выбор из него терялся, и следом открывался второй диалог.
- Открытые ролики YouTube, которым сервер файла отвечает 403, скачиваются запасным файлом (часто 360p). Сообщение больше не говорит, что доступ к ролику запрещён.

## 1.2.0 — 2026-09-30

### Added
- Скачивание ролика, встроенного в обычную страницу: вставь адрес статьи, Качалка найдёт плеер YouTube, ВК, Rutube, Vimeo и других, либо файл mp4.
- Если на странице несколько роликов, в окне можно выбрать, какой скачать. Один ролик уходит в загрузку сразу.
- Установщик 1.2.0 ставится поверх уже установленной Качалки (`%LocalAppData%\Kachalka`) и не трогает папку «Скачанное».

## 1.1.0 — 2026-08-04

### Added
- ВК через `vk.ru`, сертификаты для Windows и cookies для закрытых роликов.
