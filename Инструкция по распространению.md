# Достаточно ли отправить Kachalka-Setup.exe?

## Короткий ответ

**Да.** Одному человеку достаточно файла `dist\Kachalka-Setup.exe` (~100 МБ). Python, ffmpeg и yt-dlp уже внутри — ставить отдельно не нужно.

## Что делает Setup

- Ставит приложение в `%LocalAppData%\Kachalka` (без прав администратора)
- Создаёт ярлык в меню «Пуск» (и на рабочий стол, если отметили)
- После установки можно сразу запустить «Качалку»

## Что нужно у получателя

| Нужно | Комментарий |
|--------|-------------|
| Windows 10/11 | Целевая платформа сборки |
| Интернет | Только чтобы качать видео, не для установки |
| WebView2 | Обычно уже есть с Edge; если окно не откроется — [скачать Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) |

## На что предупредить

1. **Антивирус** — у exe из PyInstaller иногда ложное срабатывание; «разрешить» / «доверить».
2. **SmartScreen** — «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае» (пока нет цифровой подписи).
3. **Не** отправлять только `Kachalka.exe` без папки `_internal` — сломается. Setup как раз кладёт всё целиком.
4. Portable-вариант без установки: вся папка `dist\Kachalka\` целиком (не один .exe).

## Обновление уже установленной Качалки

Тот же файл `Kachalka-Setup.exe`. AppId не меняется, поэтому повторный запуск ставит новую версию в `%LocalAppData%\Kachalka` поверх старой. Папку «Скачанное» установщик не удаляет. Если Качалка была открыта, мастер попросит её закрыть, чтобы заменить файлы.

## Итог

Отправлять: **`Kachalka-Setup.exe`**.  
Альтернатива без установки: zip папки **`dist\Kachalka\`**.

Код менять не требуется — это инструкция по распространению.
